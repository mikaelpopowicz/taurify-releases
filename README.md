# Taurify

Public installers for the Taurify desktop app. This repository does not contain source code.

**[Download the latest version](https://github.com/mikaelpopowicz/taurify-releases/releases/latest)**

- **macOS (Apple Silicon):** the `.dmg`
- **Windows:** the `-setup.exe`

A Windows `.msi` is also attached if you prefer it.

On macOS, first launch may require a right-click → **Open**.
